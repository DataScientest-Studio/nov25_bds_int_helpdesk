Dieses Projekt entwickelt ein KI-gestütztes System zur automatisierten Helpdesk-Performance-Analyse. Auf Basis von Jira-Ticketdaten werden Mitarbeiter-Performance-Scores berechnet, Cluster gebildet und Manager-Bewertungen durch Maschinelles Lernen vorhergesagt.

This project develops an AI-driven system for automated helpdesk performance analysis. Based on Jira ticket data, employee performance scores are computed, clusters are formed, and manager ratings are predicted through machine learning.

Winsorisierung (99. Perzentil)

Winsorization (99th percentile)

Begründung: Extremwerte bei z.B. total_tickets oder avg_resolution_days verzerren Clustering. Winsorisierung kappt Werte über dem 99. Perzentil, ohne Datenpunkte zu verlieren — Datenverlust durch Entfernen von Ausreißern wird vermieden.

Rationale: Extreme values (e.g., in total_tickets or avg_resolution_days) distort clustering. Winsorization caps values above the 99th percentile without losing data points — avoids data loss from removing outliers.

3

RobustScaler

RobustScaler

Begründung: Normierung via IQR (Interquartilsabstand) statt Standardabweichung → robust gegen verbleibende Ausreißer und schiefe Verteilungen. Besser als StandardScaler bei rechtsschiefen Helpdesk-Daten (viele niedrige Werte, wenige Extreme).

Rationale: Normalization via IQR (interquartile range) instead of standard deviation → robust against remaining outliers and skewed distributions. Better than StandardScaler for right-skewed helpdesk data (many low values, few extremes).

Per-Assignee Feature Engineering

Per-Assignee Feature Engineering

def compute_employee_features(df_snap, df_history, global_median_resolution):
    """Berechnet 17 Features pro Mitarbeiter (min. 5 Tickets)."""

    results = []
    for assignee, group in df_snap.groupby('assignee'):
        if len(group) < 5:
            continue  # Mindest-Ticket-Schwelle

        # Effizienz
        resolution_days = group['resolution_time_days'].dropna()
        features = {
            'assignee': assignee,
            'median_resolution_days': resolution_days.median(),
            'avg_resolution_days': resolution_days.mean(),
            'std_resolution_days': resolution_days.std(),
            'pct_fast_resolved': (resolution_days < global_median_resolution).mean(),

            # Volumen
            'total_tickets': len(group),
            'active_months': group['year_month'].nunique(),
            'tickets_per_month': len(group) / group['year_month'].nunique(),

            # Qualität
            'pct_reopened': (group['wfe_reopened'] > 0).mean(),
            'resolution_rate': group['status'].isin(['Closed', 'Done']).mean(),
            'avg_comments': group['issue_comments_count'].mean(),
        }
        results.append(features)

    df_features = pd.DataFrame(results)
    # NaN-Imputation
    efficiency_cols = ['median_resolution_days', 'avg_resolution_days', 'pct_fast_resolved']
    df_features[efficiency_cols] = df_features[efficiency_cols].fillna(df_features[efficiency_cols].median())
    df_features['std_resolution_days'] = df_features['std_resolution_days'].fillna(0)
    return df_features

O-Score Gewichtungsformel

O-Score Weighting Formula

def compute_o_score(df):
    """Gewichteter O-Score auf Skala 1-5."""

    # Qualität (35%) — Wiedereröffnungen wichtiger als reine Abschlussrate
    df['quality_score'] = 0.6 * (1 - df['reopen_rate']) + 0.4 * df['success_rate']

    # Effizienz (25%) — Niedrige Zeit = hoher Score (invertiert)
    df['efficiency_score'] = 1 - df['median_time_hours'].rank(pct=True)

    # Produktivität (20%) — Volumen wichtiger als Prozessschritte
    vol_pct = df['ticket_count'].rank(pct=True)
    steps_pct = df['avg_steps'].rank(pct=True)
    df['productivity_score'] = 0.6 * vol_pct + 0.4 * (1 - steps_pct)

    # Kommunikation (20%) — Erstreaktion + optimale Kommentaranzahl
    df['communication_score'] = 0.5 * df['first_touch_rate'] + 0.5 * df['comm_optimal']

    # Gewichteter Composite Score
    df['o_score_raw'] = (
        0.35 * df['quality_score'] +
        0.25 * df['efficiency_score'] +
        0.20 * df['productivity_score'] +
        0.20 * df['communication_score']
    )

    # Skalierung auf 1-5
    df['o_score'] = 1 + df['o_score_raw'] * 4
    return df

KMeans Optimierung mit Silhouette

KMeans Optimization with Silhouette

from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

def find_optimal_k(X_scaled, k_range=range(2, 9), min_cluster_pct=0.05):
    """Findet optimales k mit Silhouette + Minimum-Cluster-Constraint."""
    results = []
    n_samples = len(X_scaled)

    for k in k_range:
        km = KMeans(n_clusters=k, n_init=20, random_state=42)
        labels = km.fit_predict(X_scaled)

        # Minimum-Cluster-Constraint: jeder Cluster ≥5%
        cluster_sizes = pd.Series(labels).value_counts(normalize=True)
        if cluster_sizes.min() < min_cluster_pct:
            continue

        sil = silhouette_score(X_scaled, labels)
        results.append({'k': k, 'silhouette': sil, 'inertia': km.inertia_})
        print(f"k={k}: Silhouette={sil:.4f}, Inertia={km.inertia_:.2f}")

    # k=4: Silhouette=0.5807 — OPTIMAL
    optimal_k = max(results, key=lambda x: x['silhouette'])['k']
    return optimal_k, results

from sklearn.ensemble import VotingClassifier, RandomForestClassifier
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier

# Drei Basis-Klassifikatoren
rf  = RandomForestClassifier(n_estimators=100, max_depth=6, random_state=42)
xgb = XGBClassifier(n_estimators=100, max_depth=6,
                    learning_rate=0.1, subsample=0.8,
                    eval_metric='mlogloss', random_state=42)
lgb = LGBMClassifier(n_estimators=100, max_depth=6,
                    learning_rate=0.1, random_state=42,
                    verbose=-1)

# Soft Voting: Wahrscheinlichkeits-Durchschnitt
voting_clf = VotingClassifier(
    estimators=[('rf', rf), ('xgb', xgb), ('lgb', lgb)],
    voting='soft'  # besser kalibriert als 'hard'
)

# 5-Fold Stratified Cross-Validation
from sklearn.model_selection import cross_val_score, StratifiedKFold
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
cv_scores = cross_val_score(voting_clf, X_train, y_train, cv=cv)
print(f"CV: {cv_scores.mean():.3f} ± {cv_scores.std():.3f}")
